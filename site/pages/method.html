Method: transfer learning on chest X-rays

How an ImageNet-pretrained EfficientNet-B0 was fine-tuned into a pneumonia detector, step by step, with every choice made to keep the test-set numbers honest.

1. Data

The model uses the original Kaggle Chest X-Ray Images (Pneumonia) dataset, from Kermany et al., Cell 2018. All images are real anterior-posterior chest X-rays of children aged one to five.

2. A patient-level validation split

Kaggle's validation folder has only 16 images, far too few to choose a checkpoint or a threshold. So the train and val folders were pooled and about 10% of patients were held out as validation (573 images). Many patients have more than one X-ray, so splitting by image would leak the same patient into both sets and inflate the scores. Splitting by patient id prevents that. The test set is used only once, at the very end.

3. Model: EfficientNet-B0 with transfer learning

EfficientNet-B0 is a compact CNN (about 5 million parameters) that is accurate for its size. It starts from ImageNet weights from the timm library, its classifier is replaced with a single-logit head for pneumonia vs normal, and all layers are fine-tuned. Grayscale X-rays are resized to 256 pixels and center-cropped to 224 pixels.

4. Augmentation

  • Random resized crop covering 80 to 100% of the image
  • Rotation of up to 10 degrees and small shifts
  • Brightness and contrast jitter, to mimic different X-ray machines and exposures
  • No horizontal flip: the heart sits on the left, and flipping would create anatomy that does not exist

5. Handling class imbalance

About 74% of the training images show pneumonia. Without correction, a model can score well by leaning toward "pneumonia" for everything. Binary cross-entropy with balanced class weights keeps the normal class from being ignored during training, and recall is then pushed up deliberately with the decision threshold.

6. Training

  • Optimizer: AdamW, learning rate 3e-4 on a one-cycle schedule
  • Batch size 32, 8 epochs, about 4 minutes per epoch on a 4-core CPU
  • Checkpoint selection: best validation ROC-AUC (epoch 7, AUC 0.999)

7. Choosing the decision threshold for recall

On the validation set, the threshold is set to the highest value that keeps recall at or above 98%. That came out at 0.34. The test set is then scored once at that threshold. See why recall matters for the reasoning.

8. Grad-CAM

Hooks on the last convolutional layer capture activations and gradients of the pneumonia logit. The gradients are averaged into channel weights, combined with the activations, passed through a ReLU and upsampled onto the X-ray. Results are on the Grad-CAM page.

Reproduce it

pip install -r requirements.txt
kaggle datasets download -d paultimothymooney/chest-xray-pneumonia -p data --unzip
curl -L -o efficientnet_b0.pth https://github.com/huggingface/pytorch-image-models/releases/download/v0.1-weights/efficientnet_b0_ra-3dd342df.pth
python prepare_data.py --root data/chest_xray --out cache
mkdir -p outputs
python train.py --weights efficientnet_b0.pth --epochs 8
python evaluate.py --target-recall 0.98
python gradcam.py

The trained model (16 MB) and all metrics are in the GitHub repository.

Limitations

  • Single-site pediatric data (Guangzhou, ages 1 to 5). It says nothing about adults or other hospitals.
  • Low specificity on the official test split: about 1 in 3 healthy X-rays is flagged.
  • Some heatmaps point to shortcut features such as lines, the neck and image borders.
  • A portfolio and learning project, not a medical device.
