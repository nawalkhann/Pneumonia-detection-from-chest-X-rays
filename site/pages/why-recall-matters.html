Why recall matters in medical AI

A pneumonia model with 95% accuracy can still be dangerous. For a screening tool, the number that matters most is how many sick patients it misses. Here is how this project chose what to optimize, and what it cost.

The two kinds of mistakes

A pneumonia classifier can be wrong in two ways:

  • False negative (a miss): a child with pneumonia is told the X-ray looks fine. Treatment is delayed, and pneumonia in young children can get worse quickly.
  • False positive (a false alarm): a healthy child is flagged. A doctor takes a second look and clears the X-ray. It costs some time.

These mistakes are not equally bad. A screening model should be built to make the cheap mistake much more often than the expensive one.

Recall, precision and specificity in one minute

Why accuracy is the wrong target

About 74% of this dataset's training images show pneumonia. A model that labels every image "pneumonia" scores 74% accuracy without looking at anything. In a real clinic, where most X-rays are normal, the trick flips: a model that says "normal" every time can look highly accurate while missing every sick patient. Accuracy hides exactly the error we care about most.

The threshold is a dial

The model outputs a probability between 0 and 1. The threshold decides where "pneumonia" starts. Lower it, and the model flags more X-rays: recall goes up, and so do false alarms. Raise it, and the opposite happens. There is no free setting; the threshold is where you decide how many false alarms one caught case is worth.

The common mistake is to tune that dial on the test set. That leaks information and makes the reported numbers look better than they will be on new patients. In this project the threshold was chosen on the validation set only:

  1. Score every validation X-ray.
  2. Find the highest threshold that keeps validation recall at or above 98%.
  3. Freeze it (0.34), then score the test set once.

What it cost

On the test set the model catches 386 of 390 pneumonia cases and misses 4. It also flags 87 of 234 healthy X-rays, roughly one in three. In screening, that is the intended trade: each false alarm means a doctor spends a minute on a second look, and each miss could mean an untreated child.

The low specificity is also a signal for future work. Better calibration on data from more hospitals, and training that discourages shortcut features, would bring false alarms down without giving up recall.

Takeaways

  • Decide which error is more expensive before you choose a metric.
  • For screening, optimize recall and report specificity honestly next to it.
  • Pick the threshold on validation data and touch the test set once.
  • Use the confusion matrix, not a single accuracy number, to describe a medical model.
